꾸한성 대환장 운동회 - 관전 UI 에셋

총 18개 개별 투명 WebP 파일.

중요:
- live_leaderboard_panel.webp 및 race_result_panel.webp는 내부의 이름/순위/시간/버튼 문구를 제거한 빈 패널 버전으로 교체했습니다.
- 실제 캐릭터명, 순위, 완주 시간, 경기 결과, 버튼 문구는 React에서 동적으로 렌더링하세요.
- 나머지 배너/카운트다운/중계 관련 이미지에는 콘셉트 시트에서 생성된 예시 문구가 일부 남아 있을 수 있습니다. 동적 데이터가 필요한 용도에는 그대로 사용하지 말고 React 텍스트 레이어로 대체하거나 장식만 추출해 사용하세요.
- 자동 배경 분리 결과이므로 가장자리 잔여색/미세한 잘림은 게임 적용 전 확인하세요.
- 이미지 적용은 시각 요소에만 한정하고 게임 물리/밸런스/순위 판정 로직은 변경하지 마세요.
